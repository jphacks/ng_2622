> リーダーの決定: 指摘した場面だけ配置を手で直し、どうすれば生成で直るかも考えて仕組みに入れる。ポーズの部品（転んだ人・助け起こす人・ソファに座る人の腕）は別に作り直す。
> 確かめの正本は [`../scene-protocol.md`](../scene-protocol.md) の「生成で確かめること（裏取り）」。ここは指摘ごとの経緯を残す。

## 指摘 → 原因 → 試した直し方 → 入れたか

「指示」は 2 回目（部品と関係を書かせる段）の指示（`generate-v2.ts` の `buildItemsSystem`）、「確かめ」は座標に直してからの裏取り（`verify.ts` に足した `verifyLayout`）。
指示と確かめは一度作ったが、リーダーの判断で入れない（2026-11-11）。教室・バス停・黄色い線を部品の名前や座標で決め打ちし、しきい値を手元の 51 場面に合わせた場当たり的なもので、場所や部品が増えるたびに足すことになるため。
本筋は、部品のメタデータを足して、置き方と確かめをそこから決まる一般の形にすること（下の「本筋の設計の案」）。Award Day の後に ADR を書いてから作る。
Award Day の 30 場面は、指摘した場面だけ配置を手で直した（作り置きの JSON の関係を直して座標を計算し直し、裏取りを通した）。

## 試した確かめのしきい値（入れていない。記録として残す）

作り置きの 36 場面（`json/`・`json2/`）と、手で直した 15 場面で測った。

- `inside_furniture`: めり込んだ店員は 0.12〜0.24 m、本棚に入った女の子は 0.19 m、机に入った先生は 0.18〜0.28 m。台所のカウンターで作業する人は 0.16 m 入るが、手を付けている家具なので通す。0.1 m で分かれた。
- `tool_far`: ケーキから離れた手は 0.85 m、ジュースから離れた掃除は 0.65 m。通ってよい場面はどれも 0.19 m 以下だった。
- `platform_edge`: ホームの部品の白線は中心から z = -1.2 m、黄色い帯は -0.4〜-0.1 m。指摘の券売機は奥の端が -0.45 m。人は黄色い線の近くで電車を待つ場面があるので、確かめるのは家具と自動販売機だけ。

## 本筋の設計の案

今回の指摘は、どれも「その部品をどこに・どちら向きに置けるか」「何に触れて使うか」「何とぶつかるか」「背景に何が初めからあるか」を部品が持っていないことから来ている。これを部品のメタデータ（`assets/parts/<id>/1.json` と `parts.json`）に持たせ、場所や部品の名前を指示やコードに書かない形にする。

### 部品に持たせる 5 つの情報

| 情報 | 中身の例 | 使い道 |
|---|---|---|
| 置ける地面の区画 | 窓・扉・時計: 背景の壁ぎわだけ。券売機・ベンチ（ホーム）: 地面の部品が示す「歩ける所」だけ。ホームの部品は線路と黄色い線の内側を「置けない所」として持つ。バス停の小屋: 歩道（道路の部品の上は不可） | 置き方が区画を選ぶ・確かめが外れを落とす |
| 正面と使う相手 | 机・黒板の壁: 正面と、使う人がどちらに立つ・座るか（教室の机は黒板の側が使う人の正面）。席に座る人に話す人は、席の前ではなく横 | 置き方が向きを計算で決める（今の facing を Claude に選ばせない） |
| 触れて使う点 | ケーキ: 切る点。テーブル: 拭く面。こぼれたジュース: 掃く点。人の部品: 手や道具の先の点 | 置き方が、使う人の手・道具の先をその点に合わせる |
| ぶつかりの箱 | 机・カウンター・棚・小屋・人の足もとの箱（今の size より実際の形に近いもの） | 置き方が重ならない位置を探す・確かめが重なりを落とす |
| 背景が持っている物 | 黒板の壁: 黒板。窓の壁: 窓 3 つ。バス停の小屋: ベンチ（座れる点）。ホーム: 線路と黄色い線。台所の流し: 流しとコンロ | 2 回目の指示の部品の一覧に出す。同じ物を別の部品で足させない |

置き方（compose）は、この情報から向きと位置を計算で決める。確かめは、場所ごとの決まりではなく、次の一般の 3 つにする。

1. **置ける区画**: どの部品も、自分の「置ける地面の区画」の中にある。
2. **触れて使う点が合う**: 物に働きかける動作の人は、手や道具の先が、相手の部品の「触れて使う点」から決まった距離の中にある。
3. **ぶつからない**: ぶつかりの箱どうしが重ならない（座る・手を付けて作業する、と部品が言う相手は除く）。

### 今回の指摘がどれで直るか

| 指摘 | 直す情報 | 直す確かめ |
|---|---|---|
| 窓・扉が部屋の中に立つ | 置ける区画（壁ぎわだけ）・背景が持っている物（窓の壁が窓を持つので要らない） | 置ける区画 |
| バス停が道路の上 | 置ける区画（小屋は歩道だけ） | 置ける区画 |
| 小屋の前に別のベンチ | 背景が持っている物（小屋のベンチ） | （指示。ベンチが 2 つの場面もあるので確かめない） |
| 生徒が黒板に背を向ける | 正面と使う相手（教室の机の正面は黒板の側） | （置き方が向きを決めるので起きない） |
| 店員が机にめり込む | 正面と使う相手（座る人に話す人は横）・ぶつかりの箱 | ぶつからない |
| 掃除・ケーキを切る手が物から離れる | 触れて使う点 | 触れて使う点が合う |
| 券売機が黄色い線の線路側 | 置ける区画（ホームが線路と黄色い線の内側を置けない所として持つ） | 置ける区画 |
| 女の人がバス停から離れる | 正面と使う相手（小屋の前が「待つ人」の場所） | （置き方が決める） |
| バケツ・看板が見えない | 正面と使う相手（持ち物の側・看板の表をカメラに向ける） | （置き方が決める） |
| カフェは座っている人が合う | （場面の英文の側。部品の情報では直らない） | （1 回目の指示で扱う） |

今ある確かめのうち、窓・扉・時計の `wall_thing`（壁から 1.2 m より離れたら落とす）も名前と距離で決め打ちした形で、「置ける区画」に置き換える。それまでは、ほかに窓の部品が部屋の真ん中に立つのを止めるものが無いので残す。

## 残すこと

- 上の 5 つの情報を部品のメタデータに足す ADR を、Award Day の後に書く（issue は別に立てる）。
- 人が人や家具に隠れているかは、前の調べで確かめられなかったので、今も指示で止めている。
