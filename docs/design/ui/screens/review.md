## 決定

（2026-10-24、issue #22 で決定）

- 自分の文字起こしを「あなたの描写」として出す。自分が言ったことと模範表現を見比べて振り返れるようにするため。置き場所は、点数の内訳の下・講評と模範表現の上のカードにする（`docs/design/ui/mocks/review.html` の A 案。3 案を比べて選んだ）。
- 3 項目の重み（内容 50%・表現 25%・話し方 25%）は画面に出さない。重みは遊びながら調整し、バックエンドが持つため。
- 自分の音声の再生は、録音の PR で足す。録った WAV は iPhone に残るので、バックエンドなしで再生できる。「あなたの描写」の見出しの右にスピーカーのマークの丸いボタンを置き、タップで再生・停止する（再生中はカードの地を薄い紫にする）。音声が無いうちはマークを出さない。

（2026-11-12 に決定。きろくから開き直したとき）

- きろくの画面で記録を押すと、遊んだ直後と同じ振り返りを開き直す。中身は端末に残した記録（[`play-record.md`](../../play-record.md)）から出し、通信しない。
- 見出しは「振り返り」ではなく、遊んだ日と場面の名前（例: 11/12 図書館の二人）にする。
- 上に、遊んだ場面の 3D を出す（ゆっくり回り続け、触れない）。記録の中の配置から組むので、作り置きから外した場面や、部屋が閉じた AI の場面でも出る。遊んだ直後の振り返りには出さない（見たばかりのため）。
- 順位は出さない。記録には自分の結果しか無いため。
- 録音が残っていれば、「あなたの描写」から聴ける。
