## 決定

（2026-10-24、issue #22 で決定）

- 自分の文字起こしを「あなたの描写」として出す。自分が言ったことと模範表現を見比べて振り返れるようにするため。置き場所は、点数の内訳の下・講評と模範表現の上のカードにする（`docs/design/ui/mocks/review.html` の A 案。3 案を比べて選んだ）。
- 3 項目の重み（内容 50%・表現 25%・話し方 25%）は画面に出さない。重みは遊びながら調整し、バックエンドが持つため。
- 自分の音声の再生は、録音の PR で足す。録った WAV は iPhone に残るので、バックエンドなしで再生できる。「あなたの描写」の見出しの右にスピーカーのマークの丸いボタンを置き、タップで再生・停止する（再生中はカードの地を薄い紫にする）。音声が無いうちはマークを出さない。

（2026-11-07 に決定。発音のお手本）

- 「あなたの描写」の語を押せるようにし、押すと、お手本の読み上げ（端末の音声合成 `AVSpeechSynthesizer`・en-US）のあとに、自分の録音のその単語の部分を続けて流す。内容の正答例はあるのに、発音のお手本が無く、自分の発音と聞き比べられなかったため。
  - 単語ごとの発音の点（Azure の単語の `AccuracyScore`）と録音の中の位置（`Offset`・`Duration`）は、バックエンドが results の `words` で送る。録音の切り出しは前に 0.08 秒、後ろに 0.12 秒の余白を足す。
  - 表示は文字起こしのまま（大文字・記号つき）にし、Azure の単語を前から順に当てる。当たらなかった語は押せない。`words` が届かなかったとき（採点できなかった・古いバックエンド）は、今までどおり文だけを出す。
  - 60 点未満の単語（話し方のコツと同じ基準）だけ赤くし、点の数字は出さない。自分で気になる単語も選んで聞けるよう、すべての語を押せるようにする。
  - 録音が端末に無いときは、お手本だけを流す。
- 「こう言い換える」の直した文の右に読み上げのボタンを置き、お手本として読み上げる。自分の文の文法が誤っていると、それをそのまま読んでも正しいお手本にならないため、直した文のほうを読む。
- お手本の音声は採点に使わない（正しい抑揚には幅があり、1 本の見本と比べる採点は精度が低い。`docs/design/speech-scoring-research.md`）。ゆっくり再生は今回は入れない。
