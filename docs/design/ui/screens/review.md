## 決定

（2026-10-24、issue #22 で決定）

- 自分の文字起こしを「あなたの描写」として出す（置き場所は 2026-11-11 に変更。3 つの軸の棒のすぐ下で、模範表現は「見本の答え」に替わった）。自分が言ったことと模範表現を見比べて振り返れるようにするため。置き場所は、点数の内訳の下・講評と模範表現の上のカードにする（`docs/design/ui/mocks/review.html` の A 案。3 案を比べて選んだ）。
- 3 項目の重み（内容 50%・表現 25%・話し方 25%）は画面に出さない。重みは遊びながら調整し、バックエンドが持つため。（2026-11-11 に確かめた: 振り返りにも結果発表にも重みは出さない。重みの説明は、将来「採点方法について」の画面に置く。今回は作らない）
- 自分の音声の再生は、録音の PR で足す。録った WAV は iPhone に残るので、バックエンドなしで再生できる。「あなたの描写」の見出しの右にスピーカーのマークの丸いボタンを置き、タップで再生・停止する（再生中はカードの地を薄い紫にする）。音声が無いうちはマークを出さない。

（2026-11-11、英検の二次試験の観点に沿わせた採点に合わせて作り直す。iOS の担当のメモを取り込んだ）

- 採点は 3 つの軸: 内容 50%（場面のチェックリストの F1。言えた＝チェックリストの項目のうち言えた重み ÷ 満点、正しさ＝正しい描写 ÷ 言った描写）、表現 25%、話し方 25%（Azure）。
- 上から、難易度の札・合計・「n 位 / m 人」、3 つの軸の棒、「あなたの描写」、「場面のチェック」、「場面と合わない描写」、「次の一つ」、「見本の答え」、「言い直してみよう」、「話し方の一言」。前の「講評」「模範表現」のカードは無くなる（2026-11-11 に変更）。
- 「良かった所」と「内容の内訳」（式と円グラフ）は出さず、「もう一度この場面で話す」ボタンは作らない。出口は今までどおり結果発表に戻るだけ。
  - あなたの描写: 文字起こしの全文に、描写（content.claims）ごとの線を引く。項目に当たった描写は濃い下線（一部なら破線）、一覧に無い正しい描写（おまけ）は細い灰色の下線、場面と合わない描写はオレンジの波線（紫の補色。#F59E0B 付近。2026-11-11 のレビューで赤から変更）。位置は、描写を話した順に「前の描写が終わった位置から先」で引用をそのまま探して決め、見つからない描写には引かない。下に、出てきた線だけの凡例を出す。録音を聞き直すボタンは残す。
  - 場面のチェック: 右上に「言えた {earned} / {max}」。言えた項目はチェック付きの札で並べ、その下の「あと少し」に、一部（半分塗りの丸）と言えていない（空の丸）項目を種類の札（中心・理由・つながり・細部）と日本語で並べる。
  - 場面と合わない描写: 右上に「正しさ {correct} / {said}」。オレンジの × と引用と理由。「正しさ n / m」は「言えた」と同じ灰色の文字にする（2026-11-11 のリーダーの決定。オレンジは「場面と合わない」の印＝波線・凡例・× だけ）。無ければカードごと出さない。
  - 次の一つ: 薄い紫の地で目立たせ、gain があれば右に「+{gain} 点」。点は合計の伸び。
  - 見本の答え: 場面の description を 1 文ずつ並べ、左に、その文に当たる項目の達成の印（全部言えたら塗りのチェック・全部言えていなければ空の丸・ほかは半分塗り）。文と項目は、accept の 1 つ目の言い方が文に含まれるか（大文字小文字と句読点は見ない）で結ぶ。項目が当たらない文には印を付けない。カードの下に凡例「✓ 言えた ／ □ 次に言ってみよう」を出す（アプリのまま）。まだ言えていない項目の言い方の所を薄い紫の地にする（理由・つながりは because などから後ろ）。アプリに読み上げの仕組みが無いので、音声を聞くボタンは付けない。
  - 言い直してみよう: rewrite があるときだけ。元の文を小さく灰色、下向きの矢印、直した文を太字、理由を小さく。
  - 話し方の一言: 見出しの右に、いちばん低かった点（正確さ・流ちょうさ・抑揚）の札と、一言の文。
