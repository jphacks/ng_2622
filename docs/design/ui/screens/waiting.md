## 決定

（2026-10-24、issue #9 の認識合わせで決定。細部はモックで確かめる）

- 締め切りの確認に出す「まだ N 人が完了していません」の N は、完了していない人（話している・採点中）を数える。参加者の一覧には自分も入れ、「あなた」と印を付ける。
- 参加者の一覧と締め切りだけの簡素な画面にする（2026-10-24、モックのプレビューで変更）。仮の画像の太陽の絵・「おつかれさま」・「点数は発表まで伏せられます。」・「残り N 人」は出さない。要るとわかったら後から足す。点数は出さないので、伏せることは変わらない。
- 参加者の状態の色は紫にそろえ、アイコンの形（マイク・回転・チェック・×）で見分ける（2026-10-24、モックのプレビューで変更）。完了だけ緑にすると、画面の統一感がなくなるため。切断中だけは灰色にする。
- 「締め切って発表する」はホストの画面にだけ出す。待機の画面に入ってから 2 秒は押せない（同じ位置にある「話し終えた」の連打で押してしまうのを防ぐため）。完了していない人がいるときは、確認してから締め切る。
