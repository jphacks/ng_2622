## 決定

（2026-11-12 に決定。きろくの PR では review.md の「きろくから開き直したとき」に書いている。中身は同じ）

- きろくの画面で記録を押すと、遊んだ直後と同じ振り返りを開き直す。中身は端末に残した記録から出し、通信しない。
- 見出しは「振り返り」ではなく、遊んだ日と場面の名前（例: 11/12 駅のホーム）にする。
- 上に、遊んだ場面の 3D を出す（ゆっくり回り続け、触れない）。記録の中の配置から組むので、作り置きから外した場面や、部屋が閉じた AI の場面でも出る。遊んだ直後の振り返りには出さない（見たばかりのため）。
- 順位は出さない。記録には自分の結果しか無いため。
- 録音が残っていれば、「あなたの描写」から聴ける。
