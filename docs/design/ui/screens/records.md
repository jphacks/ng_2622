## 課題

- 振り返り（文字起こし・内容の内訳・講評・見本の答え・自分の声）は、遊んだ直後にしか見られなかった。
- 同じ場面をもう一度遊んだときに、前と比べて何が言えるようになったかを見返せなかった。

## 改善案

- 野沢さんの PR #98 は、日付順の一覧と、合計点・語数の推移のグラフを出す形だった（記録はサーバーに置く）。
- 2026-11-12 に、仮の画面を比べて「横 = 場面、縦 = その場面の記録」の形に決めた。推移の集計は、苦手の画面（次の PR）で使う。

## 決定

（2026-11-12 に決定。記録の置き場所は [ADR](../../../adr/20261112-keep-play-records-on-device-one-file-per-round.md)）

- 左上に戻る。見出しは「りれき」。
- 場面を横に並べる。真ん中に 1 つ大きく出し、左右に隣の場面が少しのぞく。端はフェードで消し、矢印は置かない。場面の並びは、最後に遊んだのが新しい順。
  - 場面は 3D で出す。ゆっくり回り続け、触って回せない。記録の中の配置から組む。
  - 3D を出すのは、選んでいる場面とその両隣（同時に 3 つまで）。それより離れた場面は、名前だけの板にする。
  - 同じ場面かどうかは、場面の ID で見る。部屋がその場で作った場面は、毎回 ID が違うので、1 回ずつ別の場面になる。
- 並びの下に、選んでいる場面の名前と「N 回あそんだ」を出す。下にスクロールしても、この行は上に残る。
- その下に、選んでいる場面の最新の採点を出す。枠では囲まない。
  - 日付、難易度、合計、内容・表現・話し方の棒。
  - 言えた項目（「言えた項目 2 / 3」と、言えた項目の札）。一部だけ言えた項目は「あと少し」に並べる。言えていない項目は出さない（振り返りで見る）。
  - 「振り返りをひらく」で、最新の記録の振り返りを開き直す。
- さらに下に、同じ場面の前の記録を、新しい順に縦に並べる（「これまで」）。行には日付・難易度・合計・言えた項目の数を出す。押すと、その記録の振り返りを開き直す。
- 開き直した振り返りは、遊んだ直後と同じ画面。順位は出さず、録音があれば聴ける（[`review.md`](./review.md)）。
- 記録が 0 件のときは、「まだきろくがありません」「あそぶと、ここに場面と採点がたまります。」と出す。
- 「苦手」への入口（上の大きなボタン。文言は仮に「苦手をぶっとばせ！」）は、押した先を作るまで出さない（次の PR）。
- Mock では、例の記録を 12 件、初めから出す（`MOCK_SAMPLE_RECORDS`。端末には書かない）。Mock で遊んで保存した記録も一緒に出る。
