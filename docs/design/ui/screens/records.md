## 課題

- 部屋が閉じると採点の結果が消えるので、遊んだ人は、自分の点数や話した量が前と比べてどう変わったかを見返せない。過去の振り返りも、遊んだ直後にしか見られない。

## 改善案

- 説明のページ（PR #98 の作り直しの案）で、ホームの入口・推移のグラフ・一覧・過去の振り返りのモックを比べて決めた。

## 決定

（2026-11-11 に決定。[ADR](../../../adr/20261111-keep-own-play-records-for-180-days.md)）

- 入口はホームの「部屋を作る」「部屋に入る」の下の「きろくを見る」。部屋のボタンより目立たせない。名前が無くても開ける。
- 上から、遊んだ日数とラウンド数、合計点の推移、話した語数の推移、ラウンドの一覧を出す。グラフの見出しの右には「最初 → 最近」を出す（最初の 3 回と最近の 3 回の平均。6 回に満たないときは半分ずつ。1 回だけなら数だけ）。
- 一覧を押すと、遊んだ直後と同じ振り返りの画面を開く。見出しは日付と場面の名前。順位は出さない。録音は残さないので、自分の声の再生は出ない。場面の配置（見本の答え・チェックリスト）は、遊んだときに残したものを使う。
- 端末には保存せず、開くたびにバックエンドから取る。取れなかったときは、取れなかったことと「もう一度読み込む」を出す。まだ遊んでいないときは「部屋で遊ぶと、ここに点数と話した語数の推移が出ます。」と出す。
- 消すボタンは置かない。消したい人はプライバシーポリシーの窓口へ連絡する。
- Mock では、12 日間で 14 ラウンドの例のきろくを初めから出し、Mock で遊んだ回を先頭に足す（アプリを閉じると消える）。
