## 課題

- 振り返り（文字起こし・内容の内訳・講評・見本の答え・自分の声）は、遊んだ直後にしか見られなかった。
- 同じ場面をもう一度遊んだときに、前と比べて何が言えるようになったかを見返せなかった。

## 改善案

- PR #98 は、日付順の一覧と、合計点・語数の推移のグラフを出す形だった（記録はサーバーに置く）。
- 2026-11-12 に、仮の画面を比べて「横 = 場面、縦 = その場面の記録」の形に決めた。推移の集計は、苦手の画面（[`weak.md`](./weak.md)）で使う。
- 同じ日の初めの形は、最新の採点の要約（合計・3 つの棒・言えた項目）と「振り返りをひらく」、前の回のカードの一覧（「これまで」）で、押すと別の画面で振り返りを開き直していた。画面を見て、押して移る所を無くし、1 枚の縦の流れにした。

## 決定

（2026-11-12 に決定。PR #114 で実装。下の 2026-11-13 の直しで変わる所がある。記録の置き場所は ADR の `docs/adr/20261112-keep-play-records-on-device-one-file-per-round.md`。PR #114 で足す）

- 左上に戻る。見出しは「りれき」。
- 場面を横に並べる。真ん中に 1 つ大きく出し、左右に隣の場面が少しのぞく。端はフェードで消し、矢印は置かない。場面の並びは、最後に遊んだのが新しい順。
  - 場面は 3D で出す。ゆっくり回り続け、触って回せない。記録の中の配置から組む。
  - 3D を出すのは、選んでいる場面とその両隣（同時に 3 つまで）。それより離れた場面は、名前だけの板にする。
  - 3D の後ろには、小さな立方体の印と場面の名前を、薄い灰色で置く。塗りの板は置かない。組み上がって描かれるまで数秒かかることがあり（シミュレータで 1〜4 秒、長いと十数秒）、その間も何も無い所を作らないため。描かれると、ジオラマの盤に隠れる。
  - 薄くして並べる隣の場面では、名前を出さず印だけにする。隣は、まとめてから薄くする（3D の後ろから印や文字が透けないよう）。
  - どの場面を選ぶかは、横のスクロールが止まってから決める。速く送ったときに、通り過ぎる場面の 3D を作って捨てないため。
  - 読み上げ（VoiceOver）では横に送れないので、場面の名前の行の操作「次の場面」「前の場面」で替える。
  - 同じ場面かどうかは、場面の ID で見る。部屋がその場で作った場面は、毎回 ID が違うので、1 回ずつ別の場面になる。
- 並びの下に、選んでいる場面の名前と「N 回あそんだ」を出す。下にスクロールしても、この行は上に残る。残った行には地の色と下の線を付け、下を流れる中身と重ならないようにする。
- 下にスクロールして戻っても、横の並びは作り直さない（3D と横の位置がそのまま残る）。
- その下に、選んでいる場面を遊んだ回の振り返りを、新しい順に縦に並べる。画面は移らず、下へスクロールすると続く。押す所は無い。
  - 回ごとに、日付と時刻の区切り（「─── 最新 11/12 14:05 ───」「─── 11/12 13:25 ───」）を置く。同じ日に何回か遊んでも見分けられるよう、時刻も出す（24 時間）。
  - 中身は遊んだ直後の振り返り（[`review.md`](./review.md)）と同じ部品で、同じ並び（難易度・合計 → 3 つの軸の棒 → あなたの描写（下線と凡例）→ 場面のチェック → 場面と合わない描写 → 次の一つ → 見本の答え → 言い直してみよう → 話し方の一言）。順位は出さない（記録には自分の結果しか無い）。
  - その回の録音が残っていれば、「あなたの描写」から聴ける。録音は、きろくを読み直すときに 1 度だけ読む。鳴らす口はきろくで 1 つを共有し、別の回を押したら前の回を止める（2 本同時に鳴らさない）。
  - 縦の流れの中には 3D を出さない（3D は横の並びの中だけ）。
  - 回の数が多い場面でも重くならないよう、回の振り返りの部分だけ遅延して作る（横の並びは遅延しない所に置いたまま）。
- 一番下は、下に行くほど地の色に溶かして、続きがあることを示す。矢印や文言は置かない。
- 3D の入った画面の重ね方（2026-11-12、シミュレータで確かめた）:
  - 不透明な画面で覆われたまま残った 3D があると、ほかの 3D（新しく作ったものも）が描き直されなくなることがある。そこで、ホームの 3D はきろく・設定が重なっている間、重なる動きが終わってから外し、戻ったらすぐ出し直す。
  - 一瞬だけ出し入れするのとは違い、画面の切り替えと同じ時には外さない。
  - それでも、新しく作った 3D が数秒〜十数秒描かれないことが残っている（原因は未特定。実機では確かめていない）。
- 記録が 0 件のときは、「まだきろくがありません」「あそぶと、ここに場面と採点がたまります。」と出す。
- 「苦手」への入口（上の大きなボタン。文言は「苦手をぶっとばせ！」で確定、2026-11-12）は、押した先を作るまで出さない（次の PR）。遷移図の点線の矢印は、苦手の画面ができたときの入口（未確定）。
- きろくの画面を閉じたら、記録の場面から組んで覚えた 3D を忘れる（遊ぶたびに増えるので、持ち続けない）。
- Mock では、例の記録を 12 件、初めから出す（`MOCK_SAMPLE_RECORDS`。端末には書かない）。Mock で遊んで保存した記録も一緒に出る。

（2026-11-13 のレビューで直すことにした。直し待ち。案 A〜C を比べて決める）

- 3D の場面はずっと見せる。下へスクロールすると、3D の上端が画面の上端に着くまでは一緒に上がり、そこで止まって固定される。その下の中身（選んだ場面を遊んだ回の振り返り）だけがスクロールする。場面を横に送って替えるのは 3D の所。止まった 3D を小さくするかどうかなど、見せ方は案ごとに違う。
  - 案 A: 見出しは上の「きろく」だけ（「りれき」は無くす）。大きな 3D の左右の端から隣の場面がのぞく。止まるときは同じ大きさのまま（「きろく」の行は流れて消え、戻るボタンが 3D の上に浮く）。3D は大きく見えるが、振り返りの見える所は画面の半分ほど。
  - 案 B: 3D と名前を白い大きなカードに入れて横に並べ、隣のカードが端からのぞく。止まると、細い帯（戻る・小さな 3D・名前・回数・ページの点）に縮む。振り返りを広く読める。
  - 案 C: 見出しを無くし、全幅の 3D の舞台（薄い紫のぼかし）に、場面の名前と回数を左下、ページの点を右下に重ねる。隣の場面は見せない。止まると舞台が低くなる（画面の 3 割ほど）。
- 「苦手をぶっとばせ！」は、下に固定したフッターのボタンにする（前の「上の大きなボタン」から変える）。下へスクロールして振り返りを読み始めたら、すっと下に隠れ、上に戻ったら出る。押した先（苦手の画面）は未確定。
- 回ごとの区切りは「─── 11/13 3:02 ───」にする（「最新」は付けない）。
- 見出し「りれき」と、3D の横の並びの見た目は、ユーザーが「あんまり」と感じた所。案ごとに変えてある（見出しを無くす・3D を大きくする・隣ののぞき方）。
