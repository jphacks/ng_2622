## 課題

- 仮の画面（下書き）に「準備完了」が出ているが、決めていない。参加者が「準備完了」を押す操作を入れるかを決める。
- 画像では「ルームコード」、文書では「部屋のコード」と呼んでいる。画面の言葉をどちらにそろえるか。

## 改善案

## 決定

- 1 部屋の人数の上限は 5 人（2026-10-24）。仮の画面の「参加者 2/8」は「2/5」になる。
- 部屋のコードは数字 4 桁（2026-10-24）。
- シーンの選び方（2026-10-24、アプリに実装）: ホストの待合だけに「シーン」のカードを出す。右上に「おまかせ」、その下にサムネイル（`assets/scenes/<id>.png`）と名前を横に 3 つ並べ、選んだものはアクセントの紫で囲む。既定は「おまかせ」で、シーンを選ぶまでスタートを押せない形にはしない（ホストが 1 回多く押さずに済むため）。選んだシーンは `start` の `sceneId` で送り、「おまかせ」なら省いて部屋の側がランダムに選ぶ。参加者には前もって見せず、ラウンドが始まったとき（`round`）に全員の画面に出る。理由: バックエンドの API（`start` の `sceneId`）にそのまま合い、選択を伝えるメッセージを足さずに済むため。
- シーンの一覧には評価の星を出さない（2026-10-25 に決定）。選ぶときに星で迷わせないため。評価は結果の画面のカードで付ける。
- 難易度で選ぶ形は、アプリの設定 1 つ（Mock は難易度、Live は今の一覧）で切り替えられるように先に入れ、Mock で確かめる。本番に作り置きが入るときに Live も切り替える（2026-10-25 に決定）。
- Live も難易度だけを選ぶ形にした（2026-10-25 に決定）。ホストは start で難易度だけを送り、場面は部屋が作り置き（`backend/src/scenes/pool`）から選んで round の sceneId で配る。待合の例の場面は Mock と同じく同梱の一覧から絵だけ出し、バックエンドは呼ばない。配置の JSON は同梱を先に見て、無い場面だけ `GET /scenes/{sceneId}/layout` で取る。手作りの一覧（`SCENE_PICK = list`）は設定で戻せるように残し、後の PR で外す。
- 難易度だけを選ぶ形に変える（2026-10-25 に決定、まだアプリには入れていない）: 作り置きの場面と新しい採点が本番に入ったら、「シーン」のカードを難易度（かんたん・ふつう・むずかしい）の選択に替える。場面は部屋がその部屋でまだ出ていないものからランダムに選び、名前もサムネイルもスタートまで見せない。手作りの 6 場面はそのときに外す。理由: ホストだけが中身を知って有利になるのを防ぐため（[`scene-protocol.md`](../../scene-protocol.md) の「AI で場面を作り置く」）。
- 場面を AI で作っている間（2026-10-26 に決定、アプリに実装）: ホストが難易度でスタートすると、部屋は場面を AI で作り（room の phase が `generating`）、作り終えると round を配る。その間は全員（ホストも参加者も）待合の画面のままで、難易度のカードがあった所に走る人のアニメーション（`LoadingRunner`）と「AI が場面を生成中…」を出す。文字には光の帯を流し、文言はいつも同じにしてどんな場面かを匂わせない。ホストの「スタート」は押せなくし（2 度押さないため）、難易度も変えられない。参加者の下の「ホストのスタートを待っています」はそのまま。左上の × は押せるままにする。画面全体を覆う表示や暗くする表示は使わない。理由: Apple の HIG に沿い、待つ間もほかのことができ、やめる手段を残すため。場面を作らない・作れなかったときは、この表示を飛ばしてそのまま始まる。
- 他のルーム（2026-11-12 に決定、アプリに実装）: ホームの「部屋に入る」を無くし、ほかの人の部屋へは待合から移る。ホストの待合だけ、部屋のコードと QR の板の下に線を引いて「他のルーム」（QR の読み取りの印と右向きの矢印）を並べる。押すと「他のルームに入る」のシート（[`join.md`](./join.md)）が開く。場面を作っている間と移っている途中は押せない。参加者の待合には出さない（× で出てから、ホームの「あそぶ」で入り直す）。ホストが抜けて参加者がホストを引き継ぐと、その人の待合に出る。
- 移るとき（2026-11-12 に決定、アプリに実装）: シートで移る先に入れそうだと分かったら、シートを閉じる。自分の部屋にほかの人がいれば（切断中の人も数える）、「この部屋を抜けて、別のルームに入りますか？」「残った人は、このまま遊べます。」と、「やめる」「入る」で確かめる。誰もいなければ確かめずに移る。移るときは、今の部屋を抜けて（`leave`）から、移る先に入る（`join`）。今の部屋のホストは、残った人の誰かに替わる（バックエンドの今の動き）。誰もいなくなった部屋は、そのまま 2 時間で消える。移っている間は「他のルーム」の矢印の所が回る印になり、入れたら移った先の待合（参加者）に替わる。確かめたあとで入れなくなっていたとき（満員になった・始まった・つながらない）は、今の部屋には戻らずホームに戻る。
