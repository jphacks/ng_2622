## 決定

（2026-10-24、issue #9 の認識合わせで決定。細部はモックで確かめる）

- 録音中は指で 3D を回せる形でモックを作る。
  - 回す方向（2026-10-24 の grill-me で決定）: 横（縦の軸まわり）は何周でも回せる。縦（見下ろす角度）は範囲を制限して動かせる。地面の裏が見えたり上下が逆になったりしないようにし、陰になった物を上から覗けるようにするため。範囲の幅はモックで触って決める（仮に 10〜75 度、最初は 28 度）。
  - 指を離すと、回した角度のまま止まる。初期の向きに戻すには、回したときだけ 3D の隅に出る「↺」ボタンを押すか、ダブルタップする。ダブルタップで戻すのは Apple の標準の操作ではない（SceneKit の標準ではカメラの切り替え）ので、気付けるようにボタンも出す。
- 回転中（play-intro）から画面を切り替えずにつなぐ（2026-10-24、モックのプレビューで変更）。3D は同じ位置・大きさのまま動かさない。上のカウントダウンが「● 録音中」と残り時間の横長のバーに入れ替わり、音量メーター（3D の下端に重ねる）と「話し終えた」が下から出てくる。仮の画像の円い残り時間はやめる。理由: 急に別の画面に移ると、見ていた 3D が途切れて気持ち悪いため。
- 録音が始まる合図は上の入れ替わりだけにし、音や振動は足さない。つなぎ目が滑らかになった分、始まりに気付けるかはモックのレビューで確かめる。
- 「話し終えた」は確認を出さずにすぐ止める。
