## 課題

- 遊んだ記録と録音を端末に残すようにしたが、消すにはアプリを消すしかなかった。
- プライバシーポリシーへのリンクを置くか（2026-11-12 に置くと決めた。きろくの PR の今の形には、まだ無い）。
- アプリの中に、プライバシーポリシーと問い合わせの URL の定義が無い。App Store Connect に入れた URL（下の決定）と同じものを、アプリの 1 か所に定義してから使う。

## 改善案

## 決定

（2026-11-12 に決定。置くもの 6 つ）

- 名前と色の変更。ホームから名前と色の欄が無くなる（合意待ちの「あそぶ」の案）ので、変えるのはここだけになる。初めの名前は、最初に開いたときの画面で決める（`first-name.md`）。変える操作の形（この画面の中で打ち替えるか、別の画面か）は推測で、まだ決めていない。
- きろくと録音をすべて消す（下の、前に決めたことのまま）。
- プライバシーポリシー: https://github.com/jphacks/ng_2622/blob/main/PRIVACY_POLICY.md（App Store Connect に入れた URL。docs/app-store/README.md）。外のブラウザで開く。
- 問い合わせの窓口: https://github.com/jphacks/ng_2622/issues（App Store Connect のサポート URL と同じ。PRIVACY_POLICY.md の「お問い合わせ」も同じ所）。外のブラウザで開く。
- ライセンスの表示: アプリが使っているライブラリのライセンス（どれを出すかは、まだ調べていない）。
- アプリの版: ios/project.yml の MARKETING_VERSION（今は 1.0.0）。

（前に決めていたこと。2026-11-12）

- ホームの右上の歯車から入る。
- 「きろくと録音をすべて消す」は、オレンジ（紫の補色。振り返りの「場面と合わない描写」と同じ色）の枠のボタンにする。押すと、回数つきの確かめ（「すべて消しますか？」「きろく N 回と録音が、この iPhone から消えます。元にもどせません。」と「やめる」「消す」）を出す。
- プライバシーポリシーへのリンクを置く（上の決定）。きろくの PR の設定の画面（今の形）には、まだ無い（アプリの中に URL の定義が無いため、ときろくの PR の settings.md にある）。
- きろくの PR で決めて作ったこと: 「保存しているきろく」に回数と録音の本数を出し、「きろくと録音は、この iPhone の中だけに保存しています。」と添える。記録が 0 件のときは消すボタンを押せない。1 件ずつ消す操作は置かない。
