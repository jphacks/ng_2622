## 課題

- 「部屋を作る」「部屋に入る」の 2 つから選ぶ形で、初めての人がどちらを押すか迷う。
- 名前と色の欄が毎回目に入るが、変えることはほとんど無い。

## 改善案

## 決定

（2026-11-12 に決定。PR #114・#116 で実装。置き方は下の 2026-11-13 の直しで変わる）

- 右上に設定の丸いボタン（歯車）を置く。
- 主ボタンは「あそぶ」の 1 つにする。押すと自分の部屋ができ、ホストとして待合に入る（前の「部屋を作る」と同じ動き。マイクの許可もここで聞く）。ほかの人の部屋に入るときも、まず「あそぶ」で自分の部屋に入り、待合の「他のルーム」から移る（[`lobby.md`](./lobby.md)）。「部屋に入る」のボタンは無くす。
- 名前と色の欄はホームから無くす。名前は最初の画面（[`first.md`](./first.md)）で決め、名前と色は設定で変える（[`settings.md`](./settings.md)）。
- 「あそぶ」の下に、きろくへの入口を白い板で置く。「あそぶ」（紫）と見た目を分け、目立たせない。板には「これまでの N 回」と回数を出す。
- 記録が 0 件のときも板は出し、「あそぶと、ここにたまります」と出す。押すと、きろくの 0 件の画面が開く。
- 待合の「他のルーム」で、確かめの後で入れなくなってホームに戻ったときは、きろくの板の下に「入れませんでした（満員）」のように理由を一言出す。ボタンの位置は動かさない。知らせは VoiceOver でも読み上げ、「あそぶ」を押すかホームから次の画面へ進むと消える。（2026-11-13 に無くした。他のルームで入れなかったときは今の待合に残る。[`lobby.md`](./lobby.md)）

（2026-11-13 のレビューで直すことにし、案 B で確定。#114・#116 の実装を直す）

- 全体が上に寄りすぎている。タイトルとジオラマを、画面の上半分の中ほどに置く。
- 主の操作は、親指の届く下の方に置く。「あそぶ」（紫の塗り）と「きろく」（枠だけ）を、同じ大きさ・同じ幅で縦に 2 つ並べる。
- 「きろく」のボタンは文字だけにする（「これまでの N 回」と時計のアイコンを外す）。「あそぶ」と粒度をそろえるため。記録が 0 件でも同じ形で出し、押すときろくの 0 件の画面が開く（推測。前の決定のまま）。
- 右上の設定の歯車は、今のまま。
- 案は 2 つ（タイトルとジオラマの順番が違う）を出し、案 B（大きなジオラマの下にタイトル、その下の方に「あそぶ」「きろく」を縦、右上に歯車）に決めた（2026-11-13）。
- 案 B の初めの絵は空きが気持ち悪く、見た目が美しくなかったので、並び順はそのままで置き方を描き直した。ジオラマとタイトルのまとまりは、歯車の行と下のボタンのあいだの空きの中で、見た目の重心が少し上（光学的な中心）に来るように置く。ジオラマとタイトルの間は狭く、タイトルとボタンの間はその 4 倍ほどにし、上の空き（歯車の行からジオラマまで）と下の空き（タイトルからボタンまで）はおよそ 2 : 3 にする。ジオラマは画面の幅の 8 割ほどまで大きくする（描き直した絵の目安。実装で見て合わせる）。
- 2026-11-13 に、描き直した案 B（`1-home-proposal-v3.png`）で確定した。
