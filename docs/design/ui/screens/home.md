## 決定

（2026-11-12 に決定。きろくの PR、feat/play-records-screen で実装中）

- 右上に設定の丸いボタン（歯車）を置く。
- 「部屋を作る」「部屋に入る」の下に、きろくへの入口を白い板で置く。部屋のボタン（紫）と見た目を分け、目立たせない。板には「これまでの N 回」と回数を出す。
- 記録が 0 件のときも板は出し、「あそぶと、ここにたまります」と出す。押すと、きろくの 0 件の画面が開く。
- きろくと設定は、名前が無くても開ける。

（2026-11-12 の grill で決めた案。合意待ち。ユーザーの最後の「はい」を待っている）

- 「部屋を作る」と「部屋に入る」を、主ボタン「あそぶ」1 つにまとめる。押すと自分の部屋ができ、待合に入る。似たボタンが 2 つ並ぶと迷うため。
- 「あそぶ」の下に、回数つきの「きろく」の板（上の決定のまま）。右上に設定の歯車（上の決定のまま）。
- 他の人の部屋に入るのは、待合の「他のルーム」から（`lobby.md`）。「部屋に入る」の画面はホームから無くなり、待合のシートになる（`join.md`）。
- （2026-11-12 に足した。合意待ちの案）ホームから名前と色の欄を無くす。名前は最初に開いたときの画面（`first-name.md`）で決め、名前と色は設定（`settings.md`）で変える。ホームに残るのは、タイトル・ジオラマ・「あそぶ」・きろくの板・右上の設定。
