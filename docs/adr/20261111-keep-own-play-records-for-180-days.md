# 2026/11/11 本人が経過を見返せるよう、遊んだ記録を端末の ID ごとに 180 日残す

## Status
- accepted

## Situation
- アカウントは無い。端末ごとの乱数の ID（場面の評価の `reviewer_id`）だけがある。
- 部屋の Durable Object は、部屋が閉じたら採点の結果を消す。プライバシーポリシーも「部屋が閉じるまで」と書いていた。
- 部屋が AI で作った場面の配置（scenenglish.scene/2）は部屋の中にだけあり、部屋が閉じると消える。

## Context
- 遊んだ人が、自分の点数と話した量が前と比べてどう変わったかを見返せない。続けて遊ぶ理由が画面に無い。
- 過去のラウンドの振り返り（文字起こし・内容の判定・講評・見本の答え）も、遊んだ直後にしか見られない。

## Material for decision
- [シーンの評価を全体で 1 つの Durable Object に置く ADR](./20261024-store-scene-reviews-in-a-global-durable-object.md)（同じ置き方を使う）
- 画面の設計: `docs/design/ui/screens/records.md`
- 初めの PR #98 は、開発者が合言葉で全員分の記録を取り出して集計する形（`GET /records`・`scripts/records/summary.py`）だった。本人が見る画面が無く、使う人の役に立たないので作り直した。

## Decision
- 採点できたラウンドを、`PlayRecords` という Durable Object（`getByName("global")`、SQLite）に 1 行ずつ残す。音声に `X-Device-Id` が付いているときだけ残す。
- 残すのは、日時・端末の ID・場面の ID・語数・点数・文字起こし・内容の内訳・講評と、遊んだ場面の配置の JSON。配置も残すのは、部屋が閉じても振り返りを同じ画面で出し直すため。
- 表示名と録音は残さない。180 日を過ぎた行は、書き込むたびに消し、読むときも返さない。
- 読む口は本人用の `GET /records/mine` だけにする。`X-Device-Id` の端末の記録だけを返す。全員分を読む口は作らない。
- アプリはホームの「きろくを見る」から、推移とラウンドの一覧を出す。一覧からは振り返りの画面を開く。端末には保存せず、開くたびに取る。

## Consequences
- 良い面: 本人が推移と過去の振り返りを見返せる。全員分を読む口が無いので、ポリシーには「本人が見返すため」とだけ書ける。
- トレードオフ: 端末の ID は端末が作るので、ID を知られると、その人の記録を読まれる。アプリを入れ直す・機種を変えると前の記録は見られない。
- 配置の JSON を 1 行ごとに持つので、1 行が数 KB になる。1 端末に返すのは新しい 500 件まで。
- migration の tag `v5` は書き換えられない。やめるときは削除の migration を足す。
- 消すボタンは置かない。消したい人はポリシーの窓口へ連絡する（場面の評価と同じ扱い）。
