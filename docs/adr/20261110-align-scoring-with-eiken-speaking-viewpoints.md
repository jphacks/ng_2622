# 2026/11/10 採点は英検の二次試験の評価の観点と課題の形に沿わせる

## Status
- accepted

## Situation
- Award Day（2026-11-15）のファイナリスト。7 分のピッチと EXPO で審査される。11/11 に方向性を決め、11/14 に発表練習をする。
- 審査員の講評に「誰のためか、本当に課題を解くか、英語は伸びるか、2 週間使い続けられるか」「対戦の妥当性の納得できる説明」があった。
- 対象は英検の二次試験（面接）を控えた中高生とした。難易度は 3級・準2級・2級 にあたる（2026-11-09 の打ち合わせ）。
- 採点は内容 50・表現 25・話し方 25 で、話し方は Azure の発音評価、内容・表現は Claude（[20261021-score-speech-with-azure-and-claude](./20261021-score-speech-with-azure-and-claude.md)、[20261025-score-content-with-layout-and-rubric-bands](./20261025-score-content-with-layout-and-rubric-bands.md)）。
- 難易度は `easy`・`normal`・`hard` で、場面の作り置きと生成で使っている（[20261025-pre-generate-ai-scenes-and-pick-by-difficulty](./20261025-pre-generate-ai-scenes-and-pick-by-difficulty.md)）。

## Context
- 今の採点は IELTS の考え方の段階で付けていて、英検の練習として何を見ているかを説明しにくい。対象を英検の受験者にしたので、採点の軸と課題も英検に寄せたい。
- 2026-11-09 の測定（作り置きの 3 場面 × 8 通りの答え × 5 回）で、短く正しい答えの表現が 62 点、話題がずれた難しい単語の答えが 90 点台になった。級に合った表現かを見ていない。

## Material for decision
- grill の決定（2026-11-10、ユーザーとの対話）: 英検に合わせるのは評価の観点と課題の形まで。名乗るのは「英検の二次試験の評価の観点に沿った採点」まで。意欲や態度は測らないと明記する。合計の重みは変えない。表現は級の文法の範囲で見る。難易度の値は `eiken-3`・`eiken-pre2`・`eiken-2` にし、画面の名前は変えない。古い値は受け付けない。級ごとに短い問いのお題を出す。
- 英検協会の公開している二次試験の評価の観点: 応答内容、発音、語い、文法、語法、情報量、意欲や態度。課題の形は、3級が絵についての質問に答える、準2級が複数の人の動作と、状況を理由つきで言う、2級が 3 コマの絵の話（約 80 語）。過去問の文は使わない。
- 級の文法と語彙の範囲は CEFR-J を出典にする。
- 英検の配点（「33 点満点」など）は個人のサイトにしか出典が無かった。
- 比べた案:

| 案 | 中身 | 良い点 | だめな点 |
| --- | --- | --- | --- |
| 観点の名前だけ合わせる | 3 つの軸を英検の観点の名前に合わせる | 手間が最小 | 級ごとの違いが文の難しさだけになる |
| 観点と課題の形（採用） | 軸を観点に合わせ、級ごとにお題とチェックリストの形を変える | 「英検の観点に沿った」と説明できる根拠になる | 生成と採点の両方に級の形を入れる |
| 英検の点数の形まで | 成績表のように問題ごとに 0〜5 などで見せる | 英検らしく見える | 配点の出典が無く、公式の点と誤解される |

## Decision
- 3 つの軸を、英検の二次試験の評価の観点に対応させる。

| 英検の観点 | 軸 | 付け方 |
| --- | --- | --- |
| 応答内容・情報量 | 内容 | 場面ごとのチェックリストと、言ったことの正しさで付ける（[20261110-score-content-with-checklist-f1](./20261110-score-content-with-checklist-f1.md)） |
| 語い・文法・語法 | 表現 | Claude が段階で付ける。段階の説明は IELTS から、級ごとの文法と語彙の範囲（CEFR-J）に変える。級の範囲を正しく使えていれば、短くても高い段階にする |
| 発音 | 話し方 | Azure の発音評価のまま |
| 意欲や態度 | 対象外 | 録音では面接官とのやり取りを測れないので、測らないと仕様とピッチで明記する |

- 合計の重みは内容 50・表現 25・話し方 25 のまま変えない。
- アプリとピッチで名乗るのは「英検の二次試験の評価の観点に沿った採点」まで。「英検準拠」「英検の点数」とは言わない。英検は公益財団法人 日本英語検定協会の登録商標で、協会とは関係が無いことを添える。
- 難易度の値を `eiken-3`・`eiken-pre2`・`eiken-2` に変える。準2級は英検の英語の名前（Grade Pre-2）に合わせる。画面の名前（かんたん・ふつう・むずかしい）は変えない。古い値（`easy`・`normal`・`hard`）は受け付けない。
- 録音の前に、級ごとに決まった短い問いのお題を出す。場面ごとには変えない。
  - `eiken-3`: 誰が何をしている？
  - `eiken-pre2`: 誰が何をしている？なぜ？
  - `eiken-2`: 誰が何をしている？なぜ？に続けて、理由の先（結果や目的）までつなげることを促す。文面は画面の PR で試作を見て決める（「なぜ？→ つなげよう」が有力）。
- 2級は、英検の 3 コマの話ではなく「2級の文法で、状況を理由と結果でつないで説明する」練習にする（2026-11-09 の決定）。場面は 1 つなので、前後の出来事は問わない。
- 入れる順番:
  1. 採点の設計（この ADR と関連の ADR、仕様）
  2. 採点の実装。今の採点とは置き換えず、チェックリスト付きの試験用の場面 3 つで確かめる
  3. 文から場面を作る生成の設計
  4. 生成の実装。チェックリストの生成と、生成の出力の形の変更を含む
  5. 30 場面を作り直し、採点で呼ぶ関数と難易度の値を切り替え、古い採点と古い場面を消す

## Consequences
- 良い面: 審査で「何を見て採点しているか」を英検の観点の名前で説明できる。級ごとにお題と項目が変わるので、級の練習として使う意味が出る。
- 良い面: 表現の点が、難しい単語を並べるほど上がる傾向を直せる。
- トレードオフ: 意欲や態度は測らないので、英検の観点を全部は見ていない。そのことを隠さず言う。
- トレードオフ: 難易度の値を変えると、アプリ・バックエンド・作り置きの場面をいっせいに直すことになる。古い値を受け付けないので、切り替えるまで今の審査に出しているビルドは公開しない。
- 5 で切り替えるまで、新しい採点は本番で使われない。それまでは単体テストとぶれの測定で確かめる。
- [20261025-score-content-with-layout-and-rubric-bands](./20261025-score-content-with-layout-and-rubric-bands.md) のうち、表現を IELTS の考え方で段階にする条項を置き換える。
- [20261025-pre-generate-ai-scenes-and-pick-by-difficulty](./20261025-pre-generate-ai-scenes-and-pick-by-difficulty.md) のうち、難易度の値（`easy`・`normal`・`hard`）を置き換える。難易度ごとに作り置き、待合で難易度だけを選ぶことは存続する。
